# C.E.R. — Claude Migration Package

## Purpose
This package is a full-fidelity transfer of the Cobblemon: Ecological Resonance (C.E.R.) project context available to the sending ChatGPT project at migration time.

**Do not treat this as a curated summary.** The goal is to preserve the project's history, decisions, proposals, unresolved questions, governance, mod research, and implementation context so the receiving Claude project can reconstruct and maintain its own canonical memory.

## Required ingestion order
1. Read this file.
2. Read `PROJECT_MEMORY_MIGRATION.md`.
3. Read `Project_Governance_Protocol.docx` in full.
4. Read `Authorities_Archive.docx` in full.
5. Read `Master_Mod_Index.docx` and `Cobblemon_Deep_Dive.docx`.
6. Read `Master_Archive_Part1.docx` through `Master_Archive_Part17.docx` in numerical order.
7. Read `CER_Open_Questions_and_Loose_Ends.docx`, `Missed_Questions.docx`, `CER_Reintegration_Sweep_Findings.docx`, `EcoRe_Open_Questions_and_Gaps.md`, and `EcoRe_Full_Sweep_Findings_UNINTEGRATED.md`.
8. Read `Change_Log_Archive.docx`, `Interaction_Archive.docx`, and `Supplemental_Archive.docx`.
9. Consult `EXTERNAL_SOURCE_MANIFEST.md` for links/research that were discussed alongside the archive.

## Canonicality rules
- Preserve historical material even if it is superseded. Do not silently delete old ideas.
- Distinguish **locked/confirmed**, **current proposal**, **open/unresolved**, **rejected/shelved**, **banked**, and **historical/superseded** material.
- Do not promote an old proposal merely because it appears in an archive.
- Do not demote a locked decision merely because a later conversation explored alternatives unless the archive explicitly records that decision as reopened or superseded.
- Treat the Governance Protocol and Authorities Archive as the process authority.
- Treat the Master Archive as the main content authority.
- Treat the Mod Index as the primary mod-selection/reference authority.
- Treat the Interaction Archive as the record of collaborative/process context.
- Treat the Supplemental Archive as preserved material that does not yet have a cleaner canonical home.
- Where two records conflict, surface the conflict and trace it through the Change Log/open-question material instead of guessing.

## Important migration principle
Claude should build/refresh its own project memory from this package. It should **not** replace the archive with a short summary. The archive is the evidence base; the generated memory is a navigation/working layer over that evidence.

## Reverse migration
When Claude later provides its C.E.R. memory/export back to ChatGPT, import it as a second evidence set. Merge it against this archive rather than overwriting this package wholesale.
